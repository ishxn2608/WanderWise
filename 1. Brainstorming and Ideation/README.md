# Phase 1: Brainstorming and Ideation

## Problem Statement
Travelers spend hours manually researching and planning trips — comparing prices, finding attractions, estimating costs — with no personalized guidance.

## Core Idea
An AI-powered travel planner that generates a complete day-by-day itinerary based on destination, budget, travel style, and personal interests — in seconds.

## Key Insights
- Most travel apps are generic, not personalized
- Budget awareness is often missing from itinerary tools
- Users want a starting point they can customize, not a locked plan
- Works without AI keys (demo fallback) lowers barrier to entry

## Prioritized Features
1. Destination + date + budget input
2. Travel style selector (Relaxed / Balanced / Packed)
3. Interest tags (Culture, Food, Nature, etc.)
4. AI-generated day-by-day plan with cost estimates
5. Save trips locally or to cloud (Supabase)
6. Works in demo mode with no API key required
